This is a simple, single web page project I made to test & practice my new skills with HTML. CSS, & JS

Here are some of the key things I learned

HTML:
  - How to link libraries such as Font-Awesome to be used in my HTML
  - Clear separation and identification of HTML elements through the use of Class & ID

CSS:
  - How to import fonts to be used
  - Practiced using basic properties such as Margin, Min-height, adding my imported font w/ font-family
  - Using tools such as flex display & media query to create responsiveness
  - Adding hover effects and controlling transitions

JS:
  - Creating a clean and organized JS file with clear notes for anyone who reads the code
  - Properly using Const and Let variables
  - Making fetch requests and accessing the desired quote information within the Array of objects provided
  - Using methos such as Math.floor() & Math.random() to randomly generate an index number to select the quote
  - Adding and removing ClassList to HTML elements to create responsiveness connected to CSS file
  - Using the powerful tool of Async Await functions for the API Fetch request
  - Adding functionality to the buttons by adding event listeners
